# WiseShell

WiseShell 是一个 SSH/SFTP 桌面客户端，当前版本使用 C++20、Qt Widgets、libssh 和 libvterm 构建。

项目源码位于 [`WiseShell.Cpp`](WiseShell.Cpp/)。构建、使用和测试说明见 [项目文档](WiseShell.Cpp/README.md)，平台验证情况见 [验收记录](WiseShell.Cpp/docs/ACCEPTANCE.md)。

旧 WPF 版本可通过 Git 历史查看。

源码发布和后续更新命令见 [GitHub 发布说明](PUBLISH.md)。

项目采用 [MIT 许可证](LICENSE)，第三方依赖许可见 [第三方声明](WiseShell.Cpp/THIRD_PARTY_NOTICES.md)。
